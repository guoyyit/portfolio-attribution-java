# 投资组合绩效归因与收益核算服务

服务接收按日到达的持仓估值快照与外部现金流，计算组合时间加权 / 资金加权收益，
并把组合相对基准的超额收益分解为**配置效应、选择效应、交互效应**。

## 1. 数据模型与录入约定

- 估值快照 `ValuationSnapshot`：日期、总资产市值 `totalValue`、板块市值表 `segments`。
  录入时校验：`totalValue ≥ 0`、每个板块市值 `≥ 0`、板块市值之和必须严格等于
  `totalValue`；组合与基准（`kind = PORTFOLIO | BENCHMARK`）按同一时间轴分别维护。
- 外部现金流 `CashFlow`：业务幂等键 `id`、日期、金额（正投入 / 负取出）、所属板块。
- **估值口径**：估值为**当日收盘口径**，即 `V_t` 已经包含了 t 日发生的外部现金流。
  所有现金流都必须指定板块，且板块必须出现在被查询区间的组合估值中。

### 1.1 乱序、重复与事后修正

- 录入允许任意顺序（现金流可以早于其所在板块的估值到达）。
- 现金流以 `id` 为幂等键：相同 `id` 的再次提交是**修正**（金额、日期、板块以最新
  提交整体覆盖），不会产生第二条现金流，任何区间都不会被重复计算。
- 相同 `(组合/基准, 日期)` 的估值再次提交是**事后修正**，直接覆盖旧快照。
- 查询不缓存任何结果，每次都从当前最新状态计算：历史数据修正后，受影响区间结果
  立即更新；不引用被修正数据的区间结果严格不变。

## 2. 时间加权收益（TWR）

相邻两个估值日 `t-1 → t` 构成一个子区间，收盘口径下该子区间收益率：

```
r_t = (V_t − CF_t) / V_{t-1} − 1
```

其中 `CF_t` 是落在 `(t-1, t]` 的现金流净额（正为投入）。区间 `[s, e]` 的 TWR：

```
R_TWR = ∏_{t=s+1..e} (1 + r_t) − 1
```

- **可复合性**：任意 `s ≤ m ≤ e`，`(1 + R[s,m])·(1 + R[m,e]) − 1 = R[s,e]`。
  复合在全精度（20 位小数）的增长因子上完成，只在最终输出上舍入，因此
  “直接一次计算”与“由子区间 `subReturns` 复合”的结果一致，差异不超过最终舍入误差。
- 区间查询只使用 `(startDate, endDate]` 内的现金流（见 §5）。
- `V_{t-1} = 0` 且 `V_t − CF_t = 0` 时子区间收益为 0；`V_{t-1} = 0` 但期末（剔除
  现金流后）非零时该子区间无法定义收益率，返回 `INVALID_REQUEST`。

## 3. 资金加权收益（MWR）

资金加权收益采用区间**内部收益率（IRR）**，以投资者视角构造现金流序列：

- 期初投入：`−V_start`（t = 0）
- 区间内：投入为负、取出为正，发生时刻 `t = 距期初天数 / 365`（ACT/365）
- 期末收回：`+V_end`（收盘口径，已包含 `endDate` 当日现金流，因此该日现金流
  不再单独列示，避免重复计入；其余区间内现金流正常出现）

求解使下式为 0 的年化利率 `r`（二分法，`r > −1`）：

```
NPV(r) = −V_start + Σ CF_i·(−1 投入 / +1 取出) / (1+r)^{t_i} + V_end / (1+r)^T = 0
```

MWR 与 TWR 按各自定义独立成立，不做任何相互推导。期初资产 ≤ 0 或现金流序列不存在
有意义 IRR 时返回 `MONEY_WEIGHTED_NO_SOLUTION`。

## 4. 超额收益归因（BHB）

对每个子区间 t，用**期初**权重计算单日 BHB 效应（板块 i）：

```
配置效应  A_i = (wp_i − wb_i) · rb_i
选择效应  S_i = wb_i · (rp_i − rb_i)
交互效应  I_i = (wp_i − wb_i) · (rp_i − rb_i)
```

- `wp_i / wb_i`：板块 i 在组合 / 基准期初市值中的权重。
- `rb_i`：基准板块 i 的子区间市值收益率 `Vb_i,t / Vb_i,t-1 − 1`。
- `rp_i`：组合板块 i 的持有期收益率
  `(Vp_i,t − CF_i,t) / Vp_i,t-1 − 1`，`CF_i,t` 为该子区间内流入板块 i 的现金流。
  该口径保证 `Σ_i wp_i·rp_i` 恒等于组合层面含现金流的子区间收益率 `r_t`，
  `Σ_i wb_i·rb_i = rb_t`。

单日恒等式（精确）：

```
Σ_i (A_i + S_i + I_i) = rp_t − rb_t
```

### 4.1 跨子区间的精确链接

设 `x_t = 1 + rp_t`、`y_t = 1 + rb_t`。组合与基准的区间增长因子分别为
`∏ x_t`、`∏ y_t`，区间超额收益 = `∏ x_t − ∏ y_t`。

由恒等式 `a·b − c·d = a(b − d) + d(a − c)` 逐级展开，可得每个子区间的**精确链接权重**：

```
C_t = (∏_{s<t} y_s) · (∏_{s>t} x_s)
      └─ 前序基准增长 ─┘   └─ 后续组合增长 ─┘
```

区间三项效应分别为各子区间三项效应乘以 `C_t` 后求和，且精确满足：

```
Σ_t (rp_t − rb_t)·C_t = ∏ x_t − ∏ y_t = 超额收益
```

因此**配置 + 选择 + 交互 = 同期超额收益**，仅差最终舍入误差。基准无现金流。
板块集合取区间内组合与基准出现过的全部板块并集；期初总资产为 0 的快照中
所有板块权重记为 0。

## 5. 任意区间查询与现金流归属

- 查询区间 `[startDate, endDate]`（ISO `yyyy-MM-dd`）要求两端都存在组合估值
  （归因查询还要求两端存在基准估值），否则返回 `MISSING_ENDPOINT_VALUATION`。
- 进入计算的现金流窗口为半开区间 `(startDate, endDate]`：
  - 日期等于 `startDate` 的现金流**拒绝**（`CASH_FLOW_OUTSIDE_RANGE`）：收盘口径下
    它已经计入期初估值，再纳入分子会重复计算。
  - 日期晚于 `endDate` 的现金流不进入该区间（自然忽略，不报错）。
  - 早于 `startDate` 的现金流已沉淀在期初估值中，不进入。
- 落在区间内、但当日缺少组合估值的现金流无法切分子区间，返回
  `MISSING_INTERMEDIATE_VALUATION`。
- 该窗口约定保证了把区间从任意估值日 m 切成两段、分别查询再复合，与整段一次
  查询完全一致（m 日现金流只进入右段）。

## 6. 舍入规则

| 数值 | 精度 / 舍入 |
| --- | --- |
| 内部增长因子、权重、除法中间值 | 20 位小数，`HALF_UP` |
| 对外子区间收益 `subReturns` | 12 位小数，`HALF_UP` |
| 对外区间收益 / 归因效应 | 10 位小数，`HALF_UP` |

所有“必须一致”的断言（子区间复合 = 整段、三项之和 = 超额）都在全精度因子上
建立恒等式，再做最终舍入，允许的偏差不超过 **1e-9**（测试容忍上限），
理论偏差仅来自最后一位舍入（≤ 5e-11）。

## 7. 并发一致性与重启恢复

- 写入（估值 / 现金流）先以**仅追加事件日志**落盘（每条记录 = 魔数 + 长度 +
  JSON + CRC32，写完 `fsync`），成功后才更新内存状态；两步在同一把写锁内完成。
- 查询在锁内复制出一份**不可变快照**（`Map.copyOf` / `List.copyOf`）后在锁外
  计算，因此任何查询读到的都是某一时刻完整、自洽的状态，绝不会读到部分写入
  或新旧混合数据。
- 启动时重放全部事件：估值按日期去重（后值覆盖）、现金流按 `id` 去重（后值
  覆盖），崩溃时写了一半的尾部记录因魔数 / 长度 / CRC 校验失败被忽略，
  不会留下部分生效记录。
- 数据目录由 `attribution.data-dir` 配置（默认 `./data`，日志文件 `event.log`）。

## 8. HTTP API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/portfolios/{id}/valuations` | 录入/修正估值（body 见下） |
| POST | `/api/portfolios/{id}/cash-flows` | 录入/修正现金流 |
| GET  | `/api/portfolios/{id}/returns?startDate&endDate&returnKind` | 收益查询，`returnKind = TIME_WEIGHTED`（默认）/ `MONEY_WEIGHTED` |
| GET  | `/api/portfolios/{id}/attribution?startDate&endDate` | BHB 归因 |

估值请求体示例：

```json
{ "kind": "PORTFOLIO", "date": "2026-01-01",
  "totalValue": 100, "segments": { "A": 60, "B": 40 } }
```

错误响应固定为 `{"errorCode": "...", "message": "..."}`，业务拒绝返回 HTTP 422，
请求格式 / 枚举非法返回 HTTP 400。错误原因只由请求内容与已提交数据决定，
不随请求先后顺序改变。

| errorCode | 含义 |
| --- | --- |
| `NEGATIVE_ASSET` | 总资产市值为负 |
| `NEGATIVE_HOLDING` | 某板块持仓市值为负 |
| `SEGMENT_SUM_MISMATCH` | 板块市值之和与总资产不一致 |
| `ZERO_CASH_FLOW` | 现金流金额为零 |
| `UNKNOWN_SEGMENT` | 现金流板块在查询区间的组合估值中不存在 |
| `CASH_FLOW_OUTSIDE_RANGE` | 现金流日期等于查询起始日（收盘口径下会重复计算） |
| `MISSING_ENDPOINT_VALUATION` | 缺少区间起点或终点估值（组合或基准） |
| `MISSING_INTERMEDIATE_VALUATION` | 区间内现金流发生当日缺少组合估值 |
| `INVALID_DATE_RANGE` | 起始日期晚于结束日期 |
| `MONEY_WEIGHTED_NO_SOLUTION` | 资金加权收益无解（期初资产 ≤ 0 或无有意义 IRR） |
| `INVALID_REQUEST` | 日期/JSON/枚举等请求格式非法 |

## 9. 一个算例

组合：d1 总值 100（A 60 / B 40），d2 收盘 130（A 86 / B 44），当日流入 A 板块 20。

- TWR 子区间：`(130 − 20)/100 − 1 = 10%`。
- 板块收益：A `(86−20)/60−1 = 10%`、B `44/40−1 = 10%`。
- 基准 d1 100（A 50 / B 50）、d2 105（A 55 / B 50），基准收益 5%，超额 +5%。
  板块 A：`(0.6−0.5)·0.10 + 0.5·(0.10−0.10) + (0.6−0.5)·(0.10−0.10) = 1%`；
  板块 B：`(0.4−0.5)·0 + 0.5·(0.10−0) + (0.4−0.5)·(0.10−0) = 4%`，合计 5%。
